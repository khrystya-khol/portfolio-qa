# Sign In Page Test Cases

## Standard Authentication and Form Controls

| ID | Test Case |
|---|---|
| SIN-001 | Verify that the Sign In page layout is correct and the header links are displayed correctly |
| SIN-002 | Verify that blank, malformed and non-existent credentials are rejected with an error message |
| SIN-003 | Verify that Candidate and Recruiter are redirected to the correct page after signing in |
| SIN-004 | Verify that the password visibility toggle shows and hides the entered password |

## Password Reset Workflow

| ID | Test Case |
